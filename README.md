# Client 360 · Health Score

A **client-health scoring concept for a payments processor** serving property managers. Each client gets one A–D health grade built from 9 weighted KPIs across four lenses (Revenue, Product, Operational, Risk), giving revenue, product, engineering, and risk teams a shared language for client health. It's positioned as a **churn early-warning signal** — designed to flag trouble before net revenue retention does.

The product thinking and every product decision are mine; AI did the implementation. Runs on fully **synthetic data** for a fictional processor and 16 fictional property-management clients, so it's IP-safe.

## What's in it
- **Portfolio cockpit** — average health grade, momentum, total TPV at risk, grade mix.
- **Needs-attention strip** — the salvageable (B/C) accounts sliding fastest this quarter, with a "→ projected grade" badge.
- **Live scoring model** — 9 weight sliders (with leading/lagging tags and the weighting rationale) that re-grade the whole portfolio in real time.
- **Client detail** — lens sub-scores, a 4-quarter trend with next-quarter projection, at-risk-dollars, a decline post-mortem on lost accounts, an AI health read, and an "ask about this client" chat.

## A note on the AI features (this public build)
In the live version, the health read, decline post-mortem, and chat are generated by Claude at runtime. For this **public, keyless deployment** those are pre-generated and frozen (`src/prebaked.js`), each written against that client's real computed numbers — so the demo loads instantly with no API key and no cost. The deterministic scoring, the weight sliders, and every calculation remain fully interactive.

## Run locally (optional)
Requires Node 18+.
```bash
npm install
npm run dev      # local dev server
npm run build    # production build into dist/
npm run preview  # serve the production build
```

## Deploy a public URL (Vercel)
1. Push this folder to a **new GitHub repository** (github.com → New repository → drag these files into "uploading an existing file" → commit). Do **not** upload `node_modules` — it's gitignored.
2. On **vercel.com** → **Add New → Project** → **Import** the GitHub repo.
3. Vercel auto-detects Vite; leave the build settings as-is and click **Deploy**.
4. ~60 seconds later you get a live URL (e.g. `client-360-health-score.vercel.app`). That's your public link.

Any later change pushed to GitHub auto-redeploys.

## Tech
Vite + React 18, Tailwind CSS, recharts (trend chart), lucide-react (icons). Single-page, no backend, no environment variables.
